# Aspen Bear Week

Static site for Aspen Bear Week, a habitat-restoration effort in Aspen, Colorado.

## Build

Pages are generated by `build.py` from a single nav/footer source so they cannot drift.
Output is plain HTML and CSS: **no dependencies, no build step at deploy time, no server,
no database.** GitHub Pages serves the repo as-is.

## Security posture

This site never handles money, credentials or personal data. Donations, when they open,
run through an established third-party platform and are linked, never embedded as a form
we wrote. There are no accounts, no login, no admin route and no secrets in this repo.

## Custom domain

Set `SITE_URL` in `build.py`, add a `CNAME` file containing the domain, point DNS at
GitHub Pages, then rebuild.

## Images

Photographs are illustrative and are captioned as such. They are not documentation of
specific sites, animals or events in Aspen.
